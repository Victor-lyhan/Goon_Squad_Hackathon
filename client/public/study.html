How we compared

Each run is a full two-day Relay simulation of a random New York City scenario, on the committed cache of driving distances. We ran every combination of seeds 1, 2, 3; 30, 60, 120 commuting employees; 12, 24, 48 packages; and detour limits of 8, 12, 16 minutes per commute: 81 runs planned, 81 simulated, 0 skipped (a skipped run needs a driving distance the cache does not have; it is never estimated). For every package Relay matched to a commute, the baseline is the same package sent with a standard next-day B2B courier: one dedicated trip from sender to recipient, promised by 10:30 a.m. on the next business day. It is not a same-hour courier. “Per package” always means per package Relay matched. A package with no suitable commute would go by courier at the courier’s price, so it is left out of the comparison and counted in the match rate instead. Every number that is not travel data or simulation output is in the assumptions table.

How much the saving varies from run to run

One value per run: what Relay saved per matched package in that run. Each column counts the runs in that range; a value below zero means the courier was ahead in that run.

Match rate: 53.4%

Relay matched 1,211 of 2,268 requested packages to a commute; the other 1,057 would go by courier. The rate depends on how many employees commute, how many packages are asked for and how long a detour is allowed.

On time against the courier’s promised window

The courier promises delivery by 10:30 a.m. on the next business day and is assumed to always keep that promise. Each matched package is early, on time or late against it.

On average a Relay package arrives 6 h 41 min before the courier’s promised time.

Why nothing is late here: Relay only accepts a package it can deliver by the sender’s deadline. The simulated packages were ready from Day 1, 4:00 p.m. and every deadline was at or before Day 2, 10:00 a.m., which is no later than the courier’s promise (Day 2, 10:30 a.m.), so a matched package cannot be late. The price of that rule is the match rate above, not lateness.
